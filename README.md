# NEX

Custom firmware and Android companion application
for the M5Stack STOPWATCH.

## Components

- Firmware: ESP32-S3 / ESP-IDF
- Android: NEX_Connect
- Protocol: BLE GATT

## Development

Early development.

## Repository

- `main/` — Firmware entry point
- `android/` — Android companion
- `protocol/` — Communication specifications
- `docs/` — Engineering documentation
